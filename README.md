# Healthy Fit Life website

Website for Healthy Fit Life: fitness and nutrition from a 300 lb → 185 lb transformation.

It's a plain static site (`index.html`, `styles.css`, `favicon.svg`) with no build step, so it can be hosted for free on Vercel, Netlify or GitHub Pages.
